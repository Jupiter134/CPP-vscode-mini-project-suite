# CPP-vscode-mini-project-suite
short c++ coding projects while learning the language

l1_t1  
reverse the individual numbers in an integer given from user input

l1_t2  
find the greatest common divisor for two integers given from user input

l1_t3  
determine whether the digits in an integer given from user input is a palindrome

l1_t4  
without using built-in power function, determine the result of a base and exponent given from user input in O(logn) time

l1_t5  
determine whether an integer k, given from user input, is a power of 2

l2 - all without using built-in string functions in c++ - c-strings  


l2_t1  
find the length of a given string, excluding its null character \0

l2_t2  
copies a given string from source to destination, adding \0 to make it a valid c-string, iff destination is big enough. Otherwise return NULL.  

l2_t3  
find a given character in a given string and return its index. returns -1 if char is not found or given string is empty/NULL

l2_t4  
returns a substring of a given string, using given start and end indexes (i inclusive, j exclusive) 

l2_t5  
find and replace a given character with another given character in a given string if found
